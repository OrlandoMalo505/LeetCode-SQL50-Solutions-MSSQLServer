# LeetCode SQL50 — MS SQL Server Solutions
> Solutions to the LeetCode SQL 50 challenge using T-SQL / MS SQL Server

## Overview
This repository contains my solutions to the **LeetCode SQL 50** challenge, all written in **T-SQL** for Microsoft SQL Server. It covers a wide range of SQL concepts from basic queries to advanced window functions and aggregations.

## Topics Covered
- SELECT, filtering, and sorting
- JOINs (INNER, LEFT, RIGHT, FULL)
- Aggregations and GROUP BY
- Subqueries and CTEs
- Window functions (ROW_NUMBER, RANK, PARTITION BY)
- String and date functions
